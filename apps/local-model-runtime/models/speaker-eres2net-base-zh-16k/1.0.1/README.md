# speaker-eres2net-base-zh-16k

The model artifact is stored as an ordinary Git blob and versioned with this
repository. Verify it against the byte count and SHA-256 pinned in the YAML.
`npm run model:download` remains an optional recovery path for a trusted
artifact mirror. Maintainers create the signed manifest with
`npm run model:sign` and an external Ed25519 release key.
