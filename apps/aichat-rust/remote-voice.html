设备与使用说明

先在系统蓝牙设置配对遥控器，并断开电视或其他遥控软件。默认在检测到支持的已配对遥控器后开启，无需每次手动启动；没有设备时只等待。macOS 需允许 Keepwork 使用蓝牙、辅助功能及输入监控；权限未就绪时可手动启动重试。

蓝牙接收与解码已内置，无需安装环境或本地模型。松开语音键后，录音发送给 Keepwork 云端识别，需要联网；客户端不保存录音。失败请重新录制，不会自动重传。

macOS 已确认的单只小米 HID 遥控器支持返回键清空，取消当前录音或识别，直到松开语音键才接收下一段。无法确认设备、出现多只遥控器或 Windows 系统时，请单独说“清除提示词”；语音清除需等本段识别成功。清除只处理可编辑输入框。

OK 保留系统原生回车，不额外发送第二次；识别中请等待。请在 AIChat 回复结束后发送，生成中回车会按现有规则停止回复，其他应用依自身回车规则处理。“发送提示词”和“清除提示词”整句口令只执行动作，口令文字不会填入，也不改动剪贴板。

就绪期间全局预留 F5，普通键盘的 F5 也会被拦截；停止或断连后恢复。普通口述输入到当前光标，会覆盖系统剪贴板。请先松开 Ctrl、Alt、Shift、Command 或 Win 修饰键。

“就绪，开始输入”返回 AIChat 并聚焦输入框。也可自行切换到其他应用输入；关闭设置窗口会继续运行，可从托盘重新打开并停止。
