## 使用

在托盘打开「显示桌面宠物」，然后右键桌宠，选择「自选宠物」中的角色。首项「跟随模型」启用模型跟随；大肥鱼为首个 AI 娘，其他 AI 娘保持原顺序，抱抱龙在最后。默认模型跟随模式下，此选择作为 Keepwork / Keepwork Pro 及未匹配模型的回退；需要立即固定为所选形象时，在「外观模式」选择「始终使用自选宠物」。外观偏好保存在原有桌宠偏好文件中，重启后保留。

角色包括圣女果、GPT 小龙女、哈基米、Grok 大小姐、千金金、小狐狸、GLM 嘎拉吗、小田螺、大肥鱼。选择这些外观不会更改当前会话、AIChat persona、模型、账号或麦克风权限。仍然与原有 AIChat 会话交互；本实验没有创建官方 persona 目录。

当前按真实快照切换待机、聆听、思考、说话、错误状态。高兴和睡眠图集已制作，可在本地素材预览中检查；现有桌面快照尚无相应可靠事件，因此不伪造触发。视频动作是实验性的近似映射，说话动画是预录动作，不是音量驱动嘴部或实时唇形同步。隐藏桌宠、隐藏页面或启用减少动态效果时停止播放并显示预览图。

## 来源与范围

固定源仓库：[AINiangAssets 72e804d](https://github.com/hodokoshitsunagu-arch/AINiangAssets/tree/72e804d87394fdb998244251a4e21bbb4fd3e932)。每个角色的 `assets/ainiang/<id>/sources.json` 保存视频路径、哈希、透明像素验证和状态映射。预览图从视频提取，不使用 `portraits/`。

用户在本次会话确认八位非大肥鱼角色的视频由其使用 Seedance 生成、符合授权要求，并指示实验接入；随后明确将大肥鱼视频也纳入，继续排除所有立绘。大肥鱼保留 dsh-pet 固定上游路径、来源哈希与 [MIT 声明](../assets/ainiang/deepseek/DEEPSEEK-LICENSE.txt)。这一记录对应用户指定的实验范围，不冒充官方角色目录或已完成的公开发布审核。

独立宿主记录 `scripts/ainiang-approval.cjs` 固定了 catalog、每个 manifest、来源记录和 MIT 声明的摘要。素材包不能自行声明批准；新增或修改素材需重新核对来源及范围并更新宿主记录。2027-11-17 是宿主记录的下次构建审查期限，不是推断出的著作权许可到期日。已打包程序不查询在线许可或账号目录。

## 格式与构建

- 每角色一个预览图和七张 RGBA8 PNG 图集，16 帧、250 ms/帧。Claude 外观 v2 保留原视频的 640×360 帧，以 4×4 排列；其他八位维持 192×192 横向图集。透明解码使用 libvpx-vp9。矩形帧等比适配原方形区域并裁掉相邻帧，不改变角色的显示大小。
- 原始视频仅放在忽略的缓存目录。`scripts/prepare-ainiang-assets.py` 可从固定源版本重新制作；FFmpeg 版本可能影响输出字节，生成后应核对摘要，不自动重新批准。
- 复用 `contracts/ai-pet/asset-verifier.cjs` 的大小、尺寸、PNG 块、CRC、解压边界、摘要与独立批准检查。开发合同新增诚实的 `mouthMode: prerecorded`，生产版音量口型要求未因此完成。
- Vite 启动及构建前执行宿主校验。客户端只引用打包的本地资源，不扩大远端 URL 白名单，也不接受网页指定的实验素材路径。
- `node scripts/check-ainiang-assets.cjs` 检查真实素材。`node scripts/ainiang-preview-smoke.cjs` 提供只读 localhost 预览；结束后在该终端按 Ctrl-C。

本实验首先集成 Rust 桌面；Android/iOS 尚未接入这些素材。后续需分别完成平台渲染、语音口型、正式 persona 绑定及发布验收。

## 0.2.186 本体点击与透明留白

原先前端上报整个按钮矩形，Rust 宿主又强制保留 `petPixels × (petPixels + 16)` 的命中兜底；因此即使图片透明，4× 下仍有约 448×464 逻辑像素拦截鼠标。现在只对 AI 娘实验外观使用当前帧解码 alpha 的有界占用掩码（最多 256×256、阈值 16/255），保留内部透明孔洞与外部留白穿透。宿主检查掩码尺寸、十六进制长度与布局 epoch，尚未解码或无效的掩码不退回大矩形。

画面尺寸与位置保持不变。状态点、面板与通话按钮以预览图的稳定本体边界定位，避免切帧或对话状态变化导致控件跳动。状态点不接收点击；通话按钮作为第六个独立有界区域上报。已有面板、气泡、权限/退出确认、键盘按钮激活仍可用。开始拖动后保留原生鼠标捕获直到松开，果冻变形期间同步命中映射。其他非 AI 娘外观沿用原有交互。

## 0.2.187 macOS 原生穿透与删除状态点

0.2.186 的前端透明区域保护只能证明该点击没有触发桌宠，不能证明底层软件收到了点击。原生菜单曾直接将整个画布设为可交互，却没有更新控制器缓存；Tao 的 macOS setter 又异步排入主队列，因此缓存值可能与实际 `NSWindow.ignoresMouseEvents` 不一致，后续轮询会跳过恢复。

本版在 macOS 主线程直接读取、同步设置并验证真实窗口状态，每次轮询都校正实际值；菜单覆盖同步记录缓存，其他平台也会在关闭菜单后请求恢复。超时请求迟到时恢复穿透，避免留下接收鼠标的全屏画布。移除状态点 DOM 与样式；保持 Claude 4× 视觉尺寸，点击/双击/右键/拖动仍从本体开始，已打开的面板与通话控件保留自己的交互区域。

可独立运行实际 AppKit 回归：

```bash
cd apps/aichat-rust/src-tauri
rustc --edition=2021 tests/native/pet_pointer_macos_probe.rs -l framework=AppKit -o /tmp/pet-pointer-probe

```

## 0.2.191 原生窗口裁剪
