# KeepWork 家庭平板 Launcher 演示

`../launcher.html` 为无构建依赖的单文件 H5，在浏览器打开即可。联网时加载产品截图与真实应用，桌面本身可离线操作。首次打开走开机设置；演示登录后，再次打开会选择角色；顶部「重播开机」可再次演示完整流程。

## 演示路线

开机动画 → 中英文选择 → 使用浏览器当前网络 → 家庭登录 UI → 选择孩子1／孩子2／老人1／老人2 → 个人空间 → 真实应用 → 返回桌面 → 切换家人。

产品围绕全家的第二大脑组织。每位孩子的个人空间为魔法哈奇 + 我的数字大脑 + 自己的日历；每位老人为人生几何 + 我的数字大脑 + 自己的日历。日历支持月份切换、选日、新增／修改／删除日程，按角色在本机分别保存。无预填的虚构个人日程。

应用打开后的桌面按钮、应用名称、身份提示与新标签页入口合并到屏幕最上面的状态栏，内容区不再占用第二行。

顶部可直接查看儿童／老人桌面和全屏。桌面设置支持大字、减少动态、中英文和应用打开方式；应用默认内嵌，也可新标签页打开。桌面使用固定画布等比适配，无滚动条；窄屏隐藏桌面侧栏日历，通过常用应用栏中的日历按钮打开完整日历。

## 接入边界

家庭登录采用明确的“使用演示家庭登录”按钮，不收集密码，不声称完成真实认证；另提供 https://keepwork.com/chat 的真实登录入口。四个角色是演示配置，不会创建真实账号、切换真实应用身份或提供线上应用的成员间数据隔离。日历只在本机按角色分开存储，尚未接入云日历。真实应用仍使用浏览器已有登录状态，应用窗口中有持续提示。Launcher 不传递登录 token、设备凭证或个人资料。成员权限与统一登录留待正式 Android 产品实现。

网络步骤使用浏览器在线状态，不模拟真实 Wi-Fi 配对。设备电池为图示，时间使用浏览器本地时间。英语开关只改变 Launcher 文案，不强制更改真实应用语言。离开应用时移除 iframe，不声称远端后台任务已取消。原生 Home、系统音量、OEM 升级和后台常驻均未接入。

## 固定常用应用与安装限制

2026-10-12：主应用下方固定预置微信、抖音、电话、日历、浏览器。微信／抖音在 H5 中提供官方网页版；电话交给设备已有拨号器；日历打开当前角色的本机个人日历；浏览器接受 HTTPS 地址。没有应用商店、自定义添加应用、安装或 APK 下载入口。内嵌应用移除 sandbox 的 allow-downloads。真正禁止 Android 安装仍需 OEM／设备管理策略；外部网页与新标签页不受 H5 的安装控制。

本次更名仅覆盖 Launcher，实际线上应用内部文字由其自身产品管理。地址保持 `https://keepwork.com/chat`。


## 第二大脑新手指引

2026-10-12：品牌显示为「KeepWork 家庭平板」，标语为「在数字世界中，构建属于每个人的第二大脑。」登录／角色选择左侧为「什么是第二大脑？」入口；窄屏显示同名按钮。点击后整块平板内容切换为三页指引，无滚动条。

1. 什么是第二大脑：使用用户提供的定义，探索／学习／创造三个按钮切换情境示例。
2. 如何逐渐形成：以生物脑与数字第二大脑两行对照，说明公共世界、持续互动与个人知识／记忆／作品的关系。
3. 从自己的世界开始：孩子／长辈切换展示哈奇和人生几何，点击按钮体验将一次探索／一段回忆加入示例脑。仅本次指引内存状态，不写入真实个人脑。

每页固定「返回原步骤」，底部 Home 和 Escape 同样返回；完成按钮返回登录／角色选择并保留之前的步骤和角色。支持中文与英文。内容依据用户指定的 [AI研究院项目地图](https://keepwork.com/official/docs/2026/AICompany_project_map.html) 及本次提供的说明。

验收：三页导航、三个主题切换、孩子／长辈示例、返回角色保持、Home／Escape 返回，以及390px下三页内容完整显示。


## 自建家庭用户

2026-10-12 更新：角色页不再固定生成四人。参考哈奇 `view_adventure_roles.js` 的已有角色列表／新建入口与本地访客提示，以及 LifeStory `user_events_ui.js` 的本人姓名／人物关系分别填写方式，使用「新建用户 → 选择孩子／成人／老人 → 选择称呼或DIY → 创建」流程。标签含哥哥、姐姐、孩子、爸爸、妈妈、爷爷、奶奶、弟弟、妹妹、外公、外婆，也可自由输入（最多24字符）。身份与称呼分别保存，同名称呼不合并用户。

孩子默认哈奇，老人默认人生几何；成人创建时可选数字世界。每人有独立随机ID与本机日历。新安装空列表，必须先创建；旧版已有四人和日历原样保留迁移。每页最多三位用户加一个新建入口，通过分页避免滚动。取消创建不保存；新建后选中用户，确认进入后才切换当前桌面。

浏览器验证包括三种身份、常用称呼、自定义名称、重载保留、用户日历隔离、分页和名称HTML转义。仍不创建真实KeepWork账号，不冒充云端身份隔离。
