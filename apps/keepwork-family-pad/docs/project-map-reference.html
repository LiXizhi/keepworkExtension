共享超级大脑是什么？

由研究院持续维护、并与用户共创的公共知识、场景、角色、资源和技能网络，为各产品提供可以探索、学习与创造的公共数字世界。

研究院提供什么？

提供公共数字世界，也提供打通物理与数字边界的配件，让现实中的相遇、讲述与创作接入数字世界，逐步积累为个人第二大脑。

公共脑提供知识与环境，个人脑在使用中逐渐长成。配件随具体产品推进；个人记忆独立保存，只有经授权、审核的内容才进入共创公共层。
