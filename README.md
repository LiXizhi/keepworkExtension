# Keepwork Extension for VS Code

Clone projects from Keepwork and open files in Keepwork browser.

## Features

### Clone Repository from Keepwork
1. Press `Ctrl+Shift+P` to open Command Palette
2. Type "Keepwork: Clone Repository"
3. Enter a Keepwork URL (e.g., `https://keepwork.com/{owner}/{repo}/...`)
4. The repository will be cloned via VS Code's built-in Git

### Open in Keepwork
1. Right-click any file in the Explorer
2. Select "Open in Keepwork"
3. The file will open in your browser on keepwork.com

## Requirements

- Git must be installed and available in PATH
- VS Code's built-in Git extension must be enabled
