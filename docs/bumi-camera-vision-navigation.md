# 小布米课堂摄像头与语音控制

在桌面打开「视图 → Bumi 机器人…」。连接信息下方的「课堂摄像头与语音」集中显示摄像头画面、识别结果和指令。开启小米遥控后，遥控框里也能查看这块面板。

## 查看教室里的人或物

1. 在桌面 AIChat 登录 Keepwork，选择能拍到小布米、目标和地面的固定摄像头，点「开启摄像头」。首次使用时，允许系统访问摄像头。
2. 在「识别目标或动作指令」输入「穿粉色上衣的人」或「垃圾桶」，点「只识别，不移动」。这一步可以在连接蓝牙前测试。预览在本机显示，识别时才将当前帧发给 Keepwork。
3. 核对「最近识别画面」上的拍摄时间与位置。蓝色标出小布米的双脚，可辨认朝向时会画箭头。绿色标出指定人物或物体的接地点。只认出一方时画面只标该方，多个同名目标可进一步描述位置。收到较晚的只读识别结果仍可在原图上核对。

若提示定位不可靠，保持 Bumi 窗口在前台，展开「本次识别原图」。检查画面能否同时看见小布米的双脚、胸前橙色饰板或脚尖、目标的落脚处和中间的地面。窗口隐藏会关闭摄像头并清除原图。切回后重新点「开启摄像头」，核对正在使用的设备名称。识别结果会显示拍摄至返回的总时间，支持分段计时的桌面端还会显示请求到响应头、响应头到完整结果的耗时。

方向键和「向前走一步」通过蓝牙控制，无需等待云端看图。走到目标、跟随和连续走几步时，每次观察只拍一张图并识别一次。只要这张图从拍摄到使用还在 15 秒以内，就直接按识别结果检查目标和通路。超过时限、看不清目标或通路受阻时，机器人停下并显示原因。「最近识别画面」标注的是送去识别的原图和它的拍摄时间。

## 按教室里的人或物行走

连接目标机器人，等它站稳后选择「进入行走模式」。展开「行走设置」，用「往前走一步」「后退一步」「向左转一下」「向右转一下」分别量出要使用的方向，填写当前机器人和档位的实际步幅与转角。标准档为 64/127、0.8 秒，轻柔档为 40/127、0.4 秒，加强档为 80/127、1 秒。换档后重新测量。摄像头可直接使用原图估算位置，也可标出四个地面角点并填写场地尺寸。默认招呼距离为 0.8 米。

「行走置信度阈值」适用于走到目标和跟随。默认 0.75，可填 0.01 到 1.00，本机会记住设置，从下一次任务生效。例如填 0.63，联合置信度恰好为 0.63 的画面就能通过分数检查。通路是否畅通、目标和朝向是否明确、画面是否仍可用会分别检查。

在同一输入框填写指令，点「执行指令」。使用小米 RC003 时，在开启的遥控框里按住语音键说一句，松开执行。在遥控框中键入目标可以只做识别，运动口令及其后续选择请继续用遥控器语音键说出。

| 指令 | 现场表现 |
| --- | --- |
| 看看垃圾桶 | 使用摄像头只读识别，可核对照片上的位置。 |
| 向前走一步 | 按当前档位点动一次，到时写入停止。实际位移要现场测量。 |
| 向后走两步 / 向前走三步 | 每一步使用当前档位。开启教室摄像头，填写该方向的实测步幅。小布米会在第一步前确认前方或身后可通行，每步停稳后重新观察双脚位置和朝向。位移不符或净空不足就停下。 |
| 散步 / 三步 | 请说完整的方向和步数，例如「向前走三步」。一次可指定 1 至 10 步，支持中文和阿拉伯数字。「向前走三步」被听写成「向前走散步」时，同样识别为三步。 |
| 走到垃圾桶旁边 | 用当前画面判断是否可以走一步，停稳后看新图。画面确认到达目标旁的停靠点，任务就结束。 |
| 走到穿粉色上衣的人旁边并打招呼 | 从双脚中心、胸口朝向和可见通路估算停靠点，每次只执行一次转向或移动。停稳后拍新图，连续确认到达后挥手并说「你好呀！」。 |
| 跟着穿粉色上衣的人 | 等候时继续取新帧，看到目标走远才点动。有多个匹配者时停步并询问。用发起任务的输入方式回答「靠门的那位」。 |
| 停下来 | 取消后续动作并请求停步。也可以点面板的「停止」。 |

步数口令可以直接说「请让小布米往前迈上三小步」。像「往前挪一下，一共三步」这样的说法，会先用主窗口登录的 Keepwork 账号分析口令文字。AI 返回的方向和步数与原话一致后，再执行行走。说「向前 N 步」会提示给出具体数字。单步通过蓝牙点动，连续 2 至 10 步需开启教室摄像头，并在「行走设置」填好当前方向的一步实测距离。等待 AI 回复时也可以说「停下来」。

固定摄像头捕获由前台 Bumi 窗口持有。目标丢失、朝向不清、通路受阻、窗口切走或设备断开时，中断动作并显示原因。确认后方有足够空间才后退。点动指令通过蓝牙写入，每 100 毫秒刷新同一方向，结束后写零速，再静置 700 毫秒。自动任务需要新鲜、可靠的观察，迟到的回复不能触发运动。

### 在主聊天使用

在 Bumi 窗口勾选「允许 AIChat 主聊天查看教室摄像头并控制本次连接的机器人」。在主聊天发送「小布米，走到穿粉色上衣的人旁边并打招呼」。主聊天通过 `runWorkspaceCmd` 的 `takeCameraScreenshot` 获取同一固定摄像头的新帧，通过 `bumiClassroom` 提交任务。运动期间保持 Bumi 控制窗口在前台。需要选择目标时，可以回到原对话回答。更换机器人后需要重新授权。

## 本地验证

在仓库根目录运行 `pnpm --prefix apps/aichat-rust check`。自动化覆盖只读识别、镜像与地面坐标、连续视觉任务、语音和蓝牙控制。使用 `pnpm --prefix apps/aichat-rust dev:rust` 可启动本地开发版，按上述步骤现场核对镜头选择、标记位置、单步位移及实际停步表现。
