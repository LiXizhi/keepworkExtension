# 小布米课堂摄像头与语音控制

在桌面打开「视图 → Bumi 机器人…」。点「课堂任务」查看摄像头画面、识别结果和指令。开启小米遥控后，遥控框里也能查看这块面板。

## 查看教室里的人或物

1. 在桌面 AIChat 登录 Keepwork，选择能拍到小布米、目标和地面的固定摄像头，点「开启摄像头」。首次使用时，允许系统访问摄像头。
2. 在「识别目标或动作指令」输入「穿粉色上衣的人」或「垃圾桶」，点「只识别，不移动」。这一步可以在连接蓝牙前测试。预览在本机显示，识别时才将当前帧发给 Keepwork。
3. 核对「最近识别画面」上的拍摄时间与位置。「小布米」标出双脚的位置，可辨认朝向时会画箭头。「目标」标出指定人物或物体的接地点。只认出一方时画面只标该方，多个同名目标可进一步描述位置。收到较晚的只读识别结果仍可在原图上核对。

若提示定位不可靠，保持 Bumi 窗口在前台，展开「本次识别原图」。检查画面能否同时看见小布米的双脚、胸前橙色饰板或脚尖、目标的落脚处和中间的地面。窗口隐藏会关闭摄像头并清除原图。切回后重新点「开启摄像头」，核对正在使用的设备名称。识别结果会显示拍摄至返回的总时间，支持分段计时的桌面端还会显示请求到响应头、响应头到完整结果的耗时。

### 寻找视角

教室画面里的「寻找视角」默认是「被动视角」。使用固定教室摄像头时，要在画面里看见小布米，才能按机身朝向判断通路。

选「主导视角」后，当前摄像头当作小布米正前方的主视觉。画面里没有机器人身体时，也会寻找输入框里的目标。目标不在眼前、且近处地面允许转身时，机器人会转一下再看，每次任务最多连续寻找 4 次、累计 12 次。连续前进或后退时，用地面参照核对移动方向。

开关保存在本机 `keepwork.bumi.vision-calibration.v1` 的 `searchView` 字段，`passive` 为默认，`dominant` 为主导视角。桌面宿主要提供 `searchViewVersion: 1` 才显示开关。旧宿主不显示，请求也不带这个字段。

方向键和未开摄像头时的「向前走一步」通过蓝牙控制，无需等待云端看图。开启摄像头并勾选「前进后自动截屏，由 AI 判断是否继续行走」时，执行单步前进并在机器人停稳后，会自动使用当前正在预览的摄像头（固定教室摄像头或小布米自带的前向视频语音盒子摄像头）抓取新画面，交由 LLM 判断是否继续前进；判断可继续时再前进一步并重复检查（单次最多 10 步），判断停止、置信度不足或画面超时即停下并说明原因。取消勾选或未开启摄像头时，保持原有单步点动逻辑不变。走到目标、跟随和连续走几步时，每次观察只拍一张图并识别一次。只要这张图从拍摄到使用还在 15 秒以内，就直接按识别结果检查目标和通路。超过时限、看不清目标或通路受阻时，机器人停下并显示原因。「最近识别画面」标注的是送去识别的原图和它的拍摄时间。

## 按教室里的人或物行走

如果只想先试走，连接机器人，等它在平地站稳，点「手动遥控 → 进入行走模式」，再到「课堂任务」点「前进试走一步」。每次点击按当前档位前进一次并停步。即使勾选了自动续走，也只点动一次。试走无需开摄像头、填写步幅或勾选主聊天授权。

连接机器人，开启教室摄像头，等小布米站稳后选择「进入行走模式」。输入「走到垃圾桶旁边」，点「单图规划并行走」。需要逐步观察时，取消勾选「单图规划」，再点「执行指令」。小布米会根据画面估算目标距离和转向，确认有空间后点动一次，停稳后用新画面核对结果，再决定下一步。默认招呼距离为 0.8 米，可在「行走设置」里调整。

走向目标时，当前方向的步幅未知，首次点动需要看清至少 0.8 米的可通行地面。实际步幅由移动前后的画面估算。

执行「前进两步」这类计步口令时，每步单独检查小布米沿实际朝向会经过的空间，包括机身全宽和落脚余量。步幅留空时，每步需要看清至少 0.8 米的连续空地。填写实测步幅后，就按该方向的一步距离检查。侧面和更远处的桌椅只在伸入这段通路或挡住必要视线时影响这一步。无法估出距离、估计距离不足或判断把握不足时会停步，可以在「本次识别原图」中核对当时的画面。

固定摄像头完成四角标定后，可填写所标区域的「场地左右宽（米）」和「场地前后深（米）」，步幅可以留空。桌面版 0.2.308 会让模型标出机身全宽都能通过的地面末端，再按场地宽深计算沿行走方向的距离。地面末端明显偏离行走方向、看不清尺度或模型报告通路内有障碍时会停步。未做四角标定的机载前摄会按机器人正前方视角检查，并通过前后两帧里的同一个地面参照核对移动方向。

出现沙发、桌腿等遮挡提示时，可以展开当次照片核对。模型能定位时，「本次通路判断」会在照片上标出「疑似障碍」或「看不清处」。使用四角标定时，标记位于右半幅俯视图。在低清、超时或无法定位的画面上可能只显示原图。

如需使用本机已知的步幅或转角，可展开「行走设置」里的「手动标定步幅与转角（可选）」。标准档为 64/127、0.8 秒，轻柔档为 40/127、0.4 秒，加强档为 80/127、1 秒。切换档位会清空手动填写的数值。也可用定时单步口令测多次再取平均值，例如前进 3 次共移动 45 厘米，填入次数 3、总位移 45，点「计算并填入」即可得到每步 0.15 米。测前进时先关闭自动续走。使用固定摄像头时，还可以标出地面四角并填写场地尺寸。

「行走置信度阈值」适用于走到目标和跟随。默认 0.75，可填 0.01 到 1.00，本机会记住设置，从下一次任务生效。例如填 0.63，联合置信度恰好为 0.63 的画面就能通过分数检查。通路是否畅通、目标和朝向是否明确、画面是否仍可用会分别检查。

在同一输入框填写指令，点「执行指令」。使用小米 RC003 时，在开启的遥控框里按住语音键说一句，松开执行。在遥控框中键入目标可以只做识别，运动口令及其后续选择请继续用遥控器语音键说出。

| 指令 | 现场表现 |
| --- | --- |
| 看看垃圾桶 | 使用摄像头只读识别，可核对照片上的位置。 |
| 向前走一步 | 按当前档位点动一次。开启摄像头并勾选自动续走时，停稳后会拍照判断是否再走一步。 |
| 向后走两步 / 向前走三步 | 开启教室摄像头。步幅留空时，每步前都要能看清行进方向上至少 0.8 米、足够机身通过的空地。每步停稳后对比画面，核对是否按指令移动。较早的桌面版本可填写该方向的一步距离，或分次发出单步口令。 |
| 散步 / 三步 | 请说完整的方向和步数，例如「向前走三步」。一次可指定 1 至 10 步，支持中文和阿拉伯数字。「向前走三步」被听写成「向前走散步」时，同样识别为三步。 |
| 走到垃圾桶旁边 | 默认可预览走法，也可点「单图规划并行走」。取消勾选「单图规划」后可逐步拍照行走。 |
| 走到穿粉色上衣的人旁边并打招呼 | 从双脚中心、胸口朝向和可见通路估算停靠点，每次只执行一次转向或移动。停稳后拍新图，连续确认到达后挥手并说「你好呀！」。 |
| 跟着穿粉色上衣的人 | 等候时继续取新帧，看到目标走远才点动。有多个匹配者时停步并询问。用发起任务的输入方式回答「靠门的那位」。 |
| 停下来 | 取消后续动作并请求停步。也可以点面板的「停止」。 |

步数口令可以直接说「请让小布米往前迈上三小步」。像「往前挪一下，一共三步」这样的说法，会先用主窗口登录的 Keepwork 账号分析口令文字。AI 返回的方向和步数与原话一致后，再执行行走。说「向前 N 步」会提示给出具体数字。连续 2 至 10 步需开启教室摄像头。等待 AI 回复时也可以说「停下来」。

固定摄像头捕获由前台 Bumi 窗口持有。目标丢失、朝向不清、通路受阻、窗口切走或设备断开时，中断动作并显示原因。确认后方有足够空间才后退。点动指令通过蓝牙写入，每 100 毫秒刷新同一方向，结束后写零速，再静置 700 毫秒。自动任务需要新鲜、可靠的观察，迟到的回复不能触发运动。

### 单图规划

在「课堂任务」开启摄像头，输入「走到白色垃圾桶旁边」。0.2.318 起，支持「单图规划并行走」的桌面宿主默认勾选「单图规划」。每步按约 0.4 米估算，无需填写步幅。

- **单图规划并行走**。连接 Bumi 并进入行走模式。使用固定摄像头时，让机器人与静物目标都入镜。使用机载前摄时，让目标出现在前方画面。点击后，AI 从一张原图给出机器人自身的左转、右转和前进次数，Bumi 按当前档位逐次点动，最后停下。途中不再拍照规划，全程最多 10 次点动，可随时点「停止」。无需标定四角、填写宽深或测量转角。
- **预览走法**。点「预览走法」查看将要发送的动作，例如「左转 1 次 → 直走 3 步 → 停下」。在同一连接和机位、同一档位下立即点「单图规划并行走」，会直接执行这份走法。如果照片已过期、机器人动过或更换了目标，再点行走会先用新照片规划一次。未连接机器人时也可以预览。

### 在主聊天使用

在 Bumi 窗口勾选「允许 AIChat 主聊天查看教室摄像头并控制本次连接的机器人」。在主聊天发送「小布米，走到穿粉色上衣的人旁边并打招呼」。主聊天通过 `runWorkspaceCmd` 的 `takeCameraScreenshot` 获取同一固定摄像头的新帧，通过 `bumiClassroom` 提交任务。运动期间保持 Bumi 控制窗口在前台。需要选择目标时，可以回到原对话回答。更换机器人后需要重新授权。

## 本地验证

在仓库根目录运行 `pnpm --prefix apps/aichat-rust check`。自动化覆盖只读识别、镜像与地面坐标、连续视觉任务、语音和蓝牙控制。使用 `pnpm --prefix apps/aichat-rust dev:rust` 可启动本地开发版，按上述步骤现场核对镜头选择、标记位置、单步位移及实际停步表现。
