## 步骤

1. 使用新建 Windows 测试虚拟机/用户，无 KeepWork、Node、VS Code；保留系统默认安全设置。
2. 网页点击“下载安装”，确认选中 Windows x64 EXE，核对文件哈希；运行后应当前用户安装，无主动管理员提权，创建快捷方式并自动打开。
3. 观察“检查服务/启动 MCP/连接 AIChat”。读取 `http://127.0.0.1:8089/health`，核对 name=keepwork-mcp、所需 fsApi，以及 runtimeVersion/runtimeCommit；记录完整非敏感字段。不能仅记录 200。
4. 关闭到后台，从网页分别打开 open 与 onboarding；完全退出后重复；连续点击两次，应只有一个实例/向导，并保持当前会话。浏览器拒绝系统确认时，网页仍保留下载和重试入口。
5. 登录测试账号，选择内置 AIChat 和可用真实模型。在独立测试目录中创建大脑，核实 AGENTS.md、CLAUDE.md、非空 `_wiki/index.md` / log 等当前创建流程实际要求的文件。不要选择已有私人目录。
6. 在单独资料目录写入 `验收资料.md`，含“项目名称：安装首问验收”和本次随机生成的“验收暗号：KW-SB-<时间>-<随机值>”。通过向导授权并整理该资料，保留原文件与校验值。
7. 新对话只问“安装首问验收项目的验收暗号是什么？请给出来源文件。”问题不得包含暗号。核对真实回答与资料一致，来源指向实际知识页或原文件，并保存脱敏对话/模型标识证据。
8. 完全退出重开，确认大脑绑定保留且可读；模型失败后保留已创建目录和向导进度，手动重试，不重复执行结果不确定的写入。
9. 在测试机验证断网、8089 被非 Keepwork 服务占用、取消目录选择/权限、安装升级及卸载后用户数据保留。保留冲突服务，不由安装流程盲目终止。
