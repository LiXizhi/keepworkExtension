# Automatic migration of eligible desktop history

Eligible existing desktop conversation history will migrate automatically to the same account's home-region shared history, rather than requiring users to import every conversation manually or starting with empty mobile history. The user explicitly selected automatic migration alongside the requirement for macOS/Windows continuity at Android launch.

Eligibility is limited to verified same-account consumer conversations mapped to official characters through a supported exporter. Private custom-agent work, scheduled/peer/channel conversations, tool records, unfinished drafts, and unmapped history stay local; show migration status and preserve local originals. An unresolved local owner token is not evidence of a cloud account.

This decision does not authorize travel-triggered region migration or public persona publication. Migration itself does not delete source records; a later user-requested conversation deletion still applies to verified mapped copies so migration cannot resurrect deleted history.
