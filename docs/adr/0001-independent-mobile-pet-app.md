# Independent mobile pet application

The mobile product will be a dedicated AI Pet application for everyday AIChat assistance that works without a paired or running desktop. The user selected this boundary over a full AIChat mobile application or a desktop-dependent companion, so mobile authentication, conversations, and voice must have an independently usable service path even though the current desktop pet delegates to its retained AIChat window.

Reuse Keepwork identity and supported AIChat services where their contracts are verified. This decision does not select a mobile UI framework, create a separate assistant identity system, establish cloud data authority, or approve the reference proposal's hypothetical API routes; those integration decisions remain open.
